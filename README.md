# Graph Studio 先驅課程網站

## 使用方式

1. 解壓縮網站包。
2. 雙擊 `index.html`，即可在瀏覽器預覽。
3. 上架前，請搜尋並替換以下內容：
   - `NT$ 4,980`：確認是否為正式預售價。
   - `NT$ 9,800`：確認是否為正式售價，或刪除原價資訊。
   - `© 2026 Graph Studio`：替換為正式品牌／公司名稱。
4. 上架前請補充匯款後的報名與核帳流程。
5. 可將整個資料夾上傳至 Netlify、Cloudflare Pages、GitHub Pages，或交給課程平台／網站人員嵌入。

- 響應式桌機、平板與手機版面

- 三項學習成果
